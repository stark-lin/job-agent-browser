# Design

Language [English](DESIGN.md) · [简体中文](DESIGN.zh-CN.md)

The desktop workspace uses Astryx Neutral in light, dark and system modes. Phase 1 preserves the page layout, field order, text and workflows while changing the component system. Page rearrangement and copy improvements are planned for Phase 2.

The workspace always shows an icon-only navigation rail. Settings stays at the bottom. Browser and Inbox place the native webpage alongside the rail.

See the [design-system specification](docs/design-system.md) for component ownership, theming and verification.
